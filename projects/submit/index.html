Presented something at a meeting? Put it on the site. An officer checks each one before it shows up.

Use the form

The easiest way. Fill in your project's name, a short description, a screenshot and any links. No GitHub account or code needed.

Or open a pull request

Want Git practice? Add your project to the site's code yourself, and an officer reviews and merges it.

  1. Open data/projects.js on GitHub and click the pencil icon. GitHub makes you a copy (a fork) automatically.
  2. Copy one of the project blocks, paste it at the top of the list, and fill it in. The comments at the top of the file explain each field.
  3. For a screenshot, upload a PNG or JPG to the images/projects folder in your fork and set image to its path, like "/images/projects/my-project.png".
  4. Click Commit changes, then Create pull request. An officer reviews it, and once it's merged your project is live within a couple of minutes.
