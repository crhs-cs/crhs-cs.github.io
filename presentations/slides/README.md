# Presentation slides

Upload slides here and they show up on the [Presentations page](https://crhs-cs.github.io/presentations/)
in a minute or two.

1. Export the slides as a **PDF** (Google Slides: File > Download > PDF). PowerPoint files work too,
   but PDFs look exactly like the original.
2. Name the file like this:

   `2026-10-14 Intro to Git (Rishi B.).pdf`

   Date, then the title, then who presented in parentheses. Date and presenter are optional.
3. On this page, click **Add file > Upload files**, drag the file in, and click **Commit changes**.

The first slide becomes the card's picture. To fix a typo, rename the file (open it, click the
pencil, edit the name). To take a presentation down, open it, click **...** and **Delete file**.

GitHub can't take files over 25 MB through the website, so compress big PDFs first
(for example with an online PDF compressor) or remove large videos from the deck.
